# MERN Job Portal

A full-stack Job Portal application built using the MERN Stack (MongoDB, Express.js, React.js, Node.js).

## Features

### User
- Register and Login
- Browse available jobs
- Apply for jobs
- View application status
- Dashboard

### Recruiter
- Register and Login
- Create new jobs
- Edit jobs
- Delete jobs
- View applicants
- Accept or Reject applications
- Recruiter Dashboard

## Tech Stack

### Frontend
- React.js
- React Router
- Bootstrap
- Axios
- React Toastify

### Backend
- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- JWT Authentication
- bcryptjs

## Installation

### Backend

```bash
cd backend
npm install
npm start
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
