# 💼 MERN Job Portal

A full-stack Job Portal web application built using the **MERN Stack (MongoDB, Express.js, React.js, Node.js)**.

## 🚀 Features

### 👤 Job Seeker
- User Registration & Login
- Browse available jobs
- Apply for jobs
- Track application status
- Personal Dashboard

### 🏢 Recruiter
- Recruiter Registration & Login
- Create, Edit & Delete Jobs
- View Applicants
- Accept / Reject Applications
- Recruiter Dashboard

---

## 🛠 Tech Stack

### Frontend
- React.js
- React Router DOM
- Bootstrap 5
- Axios
- React Toastify

### Backend
- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- JWT Authentication
- bcryptjs

## ⚙️ Installation

### Backend

```bash

```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
